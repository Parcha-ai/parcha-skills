Every number on this page is collected, not entered. Agent metrics come from each gateway's live tether store (~/.hermes/plugin-data/tether/domain.db) read read-only over ssh; machine rows from /proc/uptime, /proc/loadavg, the root filesystem, hermes --version, tether version and tether doctor --json check counts; shipped items from git log origin/main. A host that cannot be reached is shown as unreachable rather than as zero.

Median latency is over a 24-hour window and is blank when there were no paired request/reply samples in it. Source: board/collect.py and board/render.py in parcha-skills; refreshed by agent-hub-board.timer.
